# Compani - Componentes y Animaciones en Flutter

Este repositorio contiene una colección de ejemplos prácticos, componentes personalizados y animaciones desarrolladas en Flutter. El proyecto está diseñado como un recurso educativo para dominar la creación de interfaces dinámicas y fluidas.

## 📚 Libro Promocional: Componentes y Animaciones en Flutter

Este proyecto es el complemento ideal para el libro **"Componentes y Animaciones en Flutter"** de DesarrolloLibre.net.

En este libro, aprenderás a:
* Crear **headers personalizados** con formas complejas usando `CustomPainter`.
* Implementar y definir **animaciones personalizadas**.
* Trabajar con widgets anidados y estructuras avanzadas.
* Dominar el uso de componentes esenciales para el desarrollo profesional.

👉 **[Accede al libro completo aquí](https://www.desarrollolibre.net/libros/componentes-y-animaciones-en-flutter)**

---

## 🚀 Contenido del Proyecto

El proyecto incluye diversos ejemplos de componentes y retos prácticos:

*   **Animaciones de Contenedores:** Implementaciones avanzadas de `AnimatedContainer`.
*   **Posicionamiento Dinámico:** Ejemplos de control de posición y layouts animados (`container_position.dart`).
*   **Retos Prácticos:** Soluciones a desafíos de diseño y animación (`reto1.dart`, `reto2.dart`).
*   **Componentes Reutilizables:** Widgets diseñados para ser integrados en cualquier aplicación.

## 🛠️ Tecnologías Utilizadas

*   **Flutter:** SDK para aplicaciones multiplataforma.
*   **Dart:** Lenguaje de programación optimizado para UI.

## ⚙️ Instalación y Uso

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/tu-usuario/compani.git
    ```
2.  **Obtener las dependencias:**
    ```bash
    flutter pub get
    ```
3.  **Ejecutar la aplicación:**
    ```bash
    flutter run
    ```
